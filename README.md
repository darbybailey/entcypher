# EntCypher

**Own your entertainment data while enabling meaningful insights**


## Overview
EntCypher is a secure entertainment data tracking system where users maintain ownership while providers can access aggregated insights through semantic translation layers.


## Core Components
- Dual-key encrypted data wallet
- Semantic cypher builder
- Gamification layer
- Provider analytics SDK
- Cross-platform interface


## Technologies Used
- Python 3.10+
- FastAPI
- SQLAlchemy
- PyNaCl
- Flutter
- React
- PostgreSQL


## Getting Started
1. Clone the repo
2. Configure `.env`
3. Start backend and frontend
4. Access dashboard at `localhost:3000`
